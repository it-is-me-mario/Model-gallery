# Figure source

`pv-reconstruction.png` is an unchanged copy of `outputs/figures/Figure3.png`
from [pv-hlca-model revision 28a444df](https://github.com/it-is-me-mario/pv-hlca-model/blob/28a444dfb966887534ec6963dd3db8b7f5fee6b4/outputs/figures/Figure3.png).
The source study is by Lorenzo Rinaldi, Raffaele Merletti, Camilla Citterio,
Nicolò Golinucci and Matteo Vincenzo Rocco,
[DOI 10.1007/s44498-026-00175-0](https://doi.org/10.1007/s44498-026-00175-0).
It illustrates the repository's reconstruction outputs. It is not evidence of
an independent gallery execution or an exact reproduction of the journal figures.
