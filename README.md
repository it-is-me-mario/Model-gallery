## Reading the collection

**Setup documented** means the source provides installation or execution instructions. **Setup to document** means those instructions need to be assembled. **Example update needed** marks an example with a known setup or code issue.

**None of the resources has been independently rerun for this catalog yet.** A source review and an executed reproduction are separate checks. The individual pages explain the current evidence and any uncertainty about a paper association.

When comparing results, keep the database release, MARIO version, scientific assumptions and calculation profile together. An updated analysis may differ from the version used in a paper.
