# MARIO tutorials

Focused examples for importing databases, adding sectors and calculating environmental footprints.

[Source repository](https://github.com/it-is-me-mario/Tutorials) · [Starting point](https://github.com/it-is-me-mario/Tutorials/tree/6ca6791f44f75270bea5254c764fd57291cf1377) · [Back to the gallery](../README.md)

## What you can learn

- Choose a focused example for a particular modelling task.
- Move from a pymrio database to MARIO, work with GTAP, or compare BONSAI GHG footprints.

## Before you run it

**Example update needed.** The examples cover several MARIO versions. The GTAP notebooks still refer to historical development branches; check compatibility before running.

MARIO distribution: `mariopy`; version: **not pinned in this catalog**.

- [Example-specific database inputs](https://www.marioproject.com/en/latest/resources/material.html) — Requirements differ by example. BONSAI and GTAP examples require the corresponding source data and access.
