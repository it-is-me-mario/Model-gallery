# Solar PV hybrid LCA

Embed the photovoltaic supply chain in a hybrid input-output model and assess EU reshoring scenarios.

[Source repository](https://github.com/it-is-me-mario/pv-hlca-model) · [Starting point](https://github.com/it-is-me-mario/pv-hlca-model/blob/28a444dfb966887534ec6963dd3db8b7f5fee6b4/notebooks/PV_HLCA_pipeline.ipynb) · [Back to the gallery](../README.md)

## What you can learn

- Add an explicit PV supply chain to a hybrid supply-use model.
- Compare reshoring scenarios, environmental and socio-economic outcomes, and sensitivity assumptions.

## Before you run it

**Setup documented.** The source provides environment files, headless drivers and a baseline comparison. A rebuild from the linked database is an adaptation of the original base; check the declared reference and tolerances before claiming paper reproduction.

MARIO distribution: `mariopy`; version: **1.0.0**.

- [Base hybrid-units database](https://zenodo.org/records/18744457) — Download the base files separately and configure their location as described in the source README.
